# AI by Design — Growth-to-Exit Roadmap

> The phased path from launch to a sellable (or owner-light) business. The CEO checks the current
> phase each weekly run and moves one concrete step forward. Phase gates are Chairman-confirmed.

**Current phase:** **Phase 1 — First Clients**

---

## Phase 0 — Foundation ✅ (shipped 2026-06-05)
Brand, site, funnel, analytics, operating system.
- [x] Brand kit produced (logos, favicon, OG, social banners) — `public/brand/`, `docs/BRAND-KIT.md`
- [x] Technical SEO (metadata, sitemap, robots, JSON-LD)
- [x] Analytics + conversion tracking (GA4, Meta Pixel, Vercel)
- [x] Resend lead→nurture→Calendly→AI-intake funnel
- [x] Postiz client + brand-launch batch (dry-run ready)
- [x] AI CEO operating system (`docs/business/`)
**Gate to Phase 1:** funnel deployed live; metrics wired.

## Phase 1 — First Clients *(current)*
Prove the funnel converts and land the first paid work.
- [ ] Instrument metrics (Supabase read-only + GA4) — OBJ1
- [ ] First 5 discovery calls booked — OBJ2.1
- [ ] First paid engagement closed — OBJ2.2
- [ ] First case study / testimonial (permissioned) — OBJ4.1
- [ ] Conversion pass on the homepage (social proof, pricing, About, FAQ) — OBJ4.2
**Gate to Phase 2:** repeatable way to book qualified calls + ≥1 closed engagement with proof.

## Phase 2 — Repeatable Acquisition
Make demand predictable and start the recurring book.
- [ ] SEO content engine producing weekly (blog + programmatic) and ranking — OBJ3
- [ ] First operating-partner **retainer** signed (recurring MRR begins) — OBJ2.3
- [ ] Referral / proof loop (each client → testimonial → next leads)
- [ ] CAC known per channel; double down on the cheapest that converts
**Gate to Phase 3:** inbound that books calls without manual push + ≥2 retainers.

## Phase 3 — Scale
Productize and delegate.
- [ ] Productized offers with clear scope + pricing (less bespoke quoting)
- [ ] VA / team delegation of content + ops (CEO promoted toward L3)
- [ ] Documented delivery process (so builds aren't owner-bound)
**Gate to Phase 4:** business runs owner-light week to week.

## Phase 4 — Asset
Owner-light cashflow or a sellable system.
- [ ] Predictable retainer MRR book
- [ ] Operations documented enough that a buyer sees a system, not a person
- [ ] Chairman decides: hold for cashflow, or sell

---

> The CEO never skips a phase gate to chase a number. Reliability and proof compound; shortcuts cost trust.
